# HW9 - Structural Design Patterns

Java implementation of the Bridge and Decorator design patterns.

## Part 1: Bridge Pattern
Payment notifications using Email, SMS, and Push channels.

Payment types include online payment, cash on delivery, and Bitcoin.

## Part 2: Decorator Pattern
Restaurant ordering system with food items, toppings, and loyalty discounts.

## Testing
JUnit 5 unit tests are included to verify the functionality of the program.
